# Raj Patil Portfolio

## Run in VS Code

1. Extract/open this folder in VS Code.
2. Open `index.html`.
3. Use the VS Code Live Server extension, or simply double-click `index.html`.

## Personalise before publishing

Search in `index.html` and replace:
- `your.email@example.com`
- LinkedIn URL
- Instagram URL
- Resume link
- The placeholder portrait area with your own photo if desired.

The site is built with plain HTML, CSS and JavaScript — no React, Bootstrap or other framework is required.
